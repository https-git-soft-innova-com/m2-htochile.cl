# /feature — Crear spec de funcionalidad nueva

@arquitecto activa el skill `spec-driven` y crea un feature spec.

## Instrucciones
1. Pregunta a Felipe qué funcionalidad necesita (si no lo dijo ya).
2. Crea la carpeta `.pi/specs/features/{nombre}/`.
3. Escribe `requirements.md` con user stories y acceptance criteria.
4. Escribe `design.md` con arquitectura, archivos a tocar y testing strategy.
5. Escribe `tasks.md` con tasks ordenados por dependencia, cada uno con agente asignado y DoD.
6. Presenta el spec completo a Felipe para **Puerta 1**.
7. NO ejecutes ningún task hasta la aprobación.

Recuerda: lee el steering del proyecto y el SDD/SOP antes de diseñar.
